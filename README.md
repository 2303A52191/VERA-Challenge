# VERA Bot Backend

This project provides the required endpoints for the VERA Challenge.

## Available endpoints

- `GET /health`
- `GET /resolve`
- `POST /detect`
- `POST /reply`

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
npm start
```

3. Open:

```bash
http://localhost:3000/health
```
